## 🔴 P0 - 关键问题

### 1. E2E 测试失败（7 个测试）

**问题描述**：
```
TypeError: gateway.registerApiKey is not a function
at new Agent src/agent/Agent.ts:91:13
```

**影响**：
- 7 个 e2e 测试失败
- 测试通过率：99.76% (2,872/2,879)

**根本原因**：
- Gateway 接口变更
- Agent 构造函数调用了不存在的方法

**修复建议**：
1. 检查 Gateway 类的 API
2. 更新 Agent 构造函数中的调用
3. 或者移除过时的 registerApiKey 调用

**优先级**：P0（影响测试套件）
